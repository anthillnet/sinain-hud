2 · Agent sessions × working sessions — attach, don't merge
A working session is attention (warmth, dwell, a thread). An agent session is a process (SessionStart → Stop from the bridge). Different substances, so they never merge — an agent session attaches to the working session whose span it launched inside and whose cwd maps to the same thread. Working : agents = 1→N; agent : working = 0-or-1.
