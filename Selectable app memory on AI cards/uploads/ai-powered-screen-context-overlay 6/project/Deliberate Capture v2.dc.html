0 · New — "Call AI" has two meanings
Hand off — the brief goes to an agent of your choice (Claude Code, ChatGPT, …) as text, via the MCP facade. Voice call — the same brief seeds a live call with sinain's voice agent. Same range, same brief composer, same redaction pass — only the transport differs. And the destination picker is one shared control: the same SEND TO row appears in every gesture's card — Call, Enrich, and any future story — so choosing a target is learned once. 4 · Call sinain — the one button
A live voice conversation with the agent (ARSinain call-bridge, WebRTC), hands-free with barge-in. The button is the only always-visible action on the HUD. Click → chooser (how much context) → brief composed & redacted → connected. Nothing from the call persists unless followed by a save — same consent boundary.
