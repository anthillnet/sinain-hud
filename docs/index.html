What it does

Sinain runs in the background on your Mac. It captures your screen frames and system audio, an LLM extracts facts and decisions from the stream, and a non-LLM pipeline writes those facts into a local SQLite knowledge graph you own.

You read it back through three surfaces. Same graph, different shapes.

HUD overlay

A glanceable feed pinned over your screen. Invisible to screen-capture tools, so it never shows up on shared meetings or recordings.

Web UI

Browse and search the knowledge graph at localhost:9500. Entities, concepts, source timestamps, who-said-what.

MCP server

Coding agents like Claude Code pull context directly from the graph through MCP. No more re-pasting old notes into every session.

Privacy

Paranoid mode runs the whole pipeline on-device: Ollama for the LLM extraction, whisper.cpp for transcription, Apple Vision for OCR. Zero network at runtime. No cloud, no API keys, no telemetry.

Cloud mode (via OpenRouter) is opt-in and uses your own API key. Either way, the knowledge graph stays on your machine — there is no Sinain server.

Auto-redaction strips API keys, credit cards, bearer tokens, and AWS keys before anything reaches the graph. Text wrapped in <private> tags is dropped at the capture layer.

How well does it work

82.8%
IPR on LongMemEval (ICLR 2025 public benchmark, 500 questions). Full audit.

On our internal meeting-recall benchmark, recall went from 37.9% to 62.7% after one specific architectural change: moving the integration step off the LLM and into deterministic code. More on that below.

The one architectural thing worth knowing

Most memory systems use an LLM for both extraction and integration. We split the two:

raw stream ↓ LLM extractor → {facts, entities, decisions} ↓ deterministic integrator (no LLM) ↓ SQLite triplestore (EAV + time, FTS5)

The LLM is variance. Code is determinism. Letting the LLM extract facts but not write them into the graph is where the recall jump came from — the integration step needed to be repeatable, and LLMs are not.

Reads use hybrid retrieval: full-text search, tag-based filter, and entity-graph backrefs in parallel, fused by reciprocal rank. Embedding-based dedup merges semantically equivalent facts on write so the graph doesn't bloat.

Install

npx @geravant/sinain@latest start

macOS only for now. Windows is on the roadmap, not in this release. You'll be asked for Screen Recording and Microphone permissions on first run. The HUD overlay is a separate .app that the setup wizard downloads from GitHub Releases.

Cloud mode needs an OpenRouter API key. Paranoid mode needs Ollama + a local model (the setup wizard pulls one for you).

Honest gaps

  • macOS only. Windows support exists in the codebase but is not validated yet.
  • The graph doesn't auto-detect when a fact has been superseded by a later contradictory one. We have confidence decay and explicit decision-tracking, but semantic supersession is still an open problem.
  • Cloud mode costs OpenRouter tokens during heavy use. Paranoid mode is free at runtime but slower (depends on your machine).
  • The setup is a CLI install, not a polished .dmg. You'll see permission prompts.
