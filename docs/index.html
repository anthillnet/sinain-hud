Context OS · ambient intelligence for builders

Sees what you see.
Hears what you hear.

Through the MCP bridge, that context follows you into the tools and agents you already use, so you do not have to copy screenshots, notes, and explanations between them. And nothing persists or leaves until you ask.

§ 02 — You, Augmented

Capture. Distill. Access. Share.

Sinain captures what matters, turns it into useful memory, makes it available to AI tools through the MCP bridge, and lets you share selected context with others when you choose.

01 / capture

Screen + system audio, continuously.

Sinain can watch your screen and listen to system audio while automatically hiding sensitive things like passwords, API keys, and private blocks before anything is sent out.

macOS nativescreen + audioOCR included
02 / distill

Facts, entities, decisions.

Sinain turns messy work activity into clear memory: people, projects, decisions, open questions, and why something was chosen. It remembers useful details so your AI can answer with the right background later — 82.8% IPR on LongMemEval (public benchmark).

MCP, web UI, HUD overlay.

§ 04 — Privacy Controls

Four modes. From cloud-fast to fully offline.

Choose how private you want Sinain to be. You can use cloud models for better speed and quality, or keep everything fully local when privacy matters most.

off

Best quality, with no extra privacy filtering.

standard · wizard default

Hides passwords, keys, and credentials before using cloud models.

strict

Sends only short summaries, not raw screen or audio text.

paranoid · fully local

Runs locally with no network calls while Sinain is active.

§ 05 — Quick Start

One command. A wizard. Three services up.

Install Sinain, answer a few setup questions, and it starts everything for you. The app downloads what it needs and guides you through permissions, privacy, and AI assistant setup.

~/projects · zsh
$ npx @geravant/sinain@latest start
# Pin @latest — npx caches forever against the unversioned spec.

▸ setup wizard — transcription · api key · agent · privacy
▸ download overlay app ~17 MB

▸ download embedding model ~90 MB
▸ install python deps
›
✓ sinain-core :9500
✓ sense_client screen + ocr
✓ overlay private · invisible
✓ sinain-agent-runner claude-code

$ _

  1. Run the wizard

    Pick transcription backend, paste an API key, choose your agent, and set privacy mode. You can also skip cloud setup and run fully local.

  2. Auto-download assets

    Sinain downloads the overlay app, screen capture helper, embedding model, and Python dependencies — then caches them locally.

  3. Services start

    Sinain core, screen capture, audio capture, OCR, overlay, and your selected agent connection start automatically.

  4. Re-run anytime

    Run setup again whenever you want to change privacy mode, update agents, or adjust configuration.

§ 06 — Connect Your Coding Agent

Connect Sinain to your AI agents with the MCP bridge.

The MCP bridge is how AI agents connect to Sinain's context. The setup wizard detects supported agents on your machine and registers Sinain for each one you choose.

▸ INSTALL FOR AGENTS
npx @geravant/sinain@latest mcp install

Re-run any time to update. Sinain can register with Claude Code, Claude Desktop, Cursor, Codex, Goose, and Junie, so each agent can access the same working context through the MCP bridge.
